# ✨ فكرة المشروع

**مستقبل الوطن — Digital Learning Platform** هي منصة تعليمية مخصصة لتقديم **دورة Python مجانية للمبتدئين**، مع نظام متكامل لإدارة المحتوى والطلاب والامتحانات والتاسكات.

المنصة مقسمة إلى تجارب مختلفة حسب نوع المستخدم:

- 👨‍🎓 **Student Dashboard** — للطلاب.
- 👨‍🏫 **Teacher Dashboard** — لإدارة المحتوى والامتحانات والتاسكات والطلاب.
- 🛡️ **Admin Panel** — للإدارة.
- 🔐 **Authentication & Role Protection** — لحماية الصفحات حسب صلاحية المستخدم.

> الهدف هو تحويل المحتوى التعليمي التقليدي إلى تجربة رقمية منظمة، تفاعلية، وسهلة الاستخدام.

# 🔐 Authentication & Security

تم بناء نظام الدخول باستخدام **Firebase Authentication**.

آلية تسجيل الدخول الحالية تعتمد على تجربة أنواع الحسابات المختلفة:

```text
Username + @admin.local
Username + @system.local
Username + @student.local
```

وبناءً على نجاح تسجيل الدخول يتم تحويل المستخدم إلى الصفحة المناسبة.

### 🛡️ Page Protection

يوجد نظام `auth-guard.js` لحماية الصفحات:

```text
Admin
Teacher
Student
```

ويتم منع المستخدم غير المسجل أو صاحب الصلاحية غير المناسبة من الوصول للصفحة.

> ⚠️ مهم: حماية الواجهة وحدها ليست بديلًا عن Firebase Security Rules. يجب ضبط قواعد Firestore وStorage وAuthentication قبل الاستخدام الفعلي.
